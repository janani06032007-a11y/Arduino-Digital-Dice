# Arduino-Digital-Dice
Digital Dice using Arduino UNO, OLED display, push button and buzzer with rolling animation and roll counter.
🎲 Digital Dice Using Arduino UNO

📌 Project Overview

The Digital Dice is a beginner-friendly embedded systems project developed using Arduino UNO and an OLED display.

Whenever the user presses a push button, the system generates a random number between 1 and 6. The result is displayed on the OLED screen with a rolling animation and a buzzer sound.

🔧 Components Used

- Arduino UNO
- 128×64 OLED Display (I2C)
- Push Button
- Piezo Buzzer
- Connecting Wires

✨ Features

- Random number generation (1–6)
- OLED number display
- Dice rolling animation
- Total roll counter
- Buzzer sound effect

⚙️ Working Principle

1. The user presses the push button.
2. Arduino detects the button input.
3. A dice rolling animation appears on the OLED.
4. Arduino generates a random number between 1 and 6.
5. The final result is displayed.
6. The roll counter increases.
7. The buzzer produces a sound effect.
